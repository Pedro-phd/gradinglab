# GradingLab

Central para gerar, aplicar e modificar looks de cor para vídeos e fotos. Estado atual: fundação técnica; editor ainda não implementado.

```bash
nvm use
pnpm install --frozen-lockfile
pnpm dev
```

Abra http://localhost:3000. Validação completa: `pnpm check`. Não é necessário configurar banco para compilar ou testar a base.
