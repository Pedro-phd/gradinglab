# Labels

Mapa completo consultado no Linear em 2026-11-13. Valores null significam ausentes, não nomes de labels inventados. Consultar antes de aplicar; não criar labels sem pedido. Um fluxo que exigir um papel ausente deve resolver essa escolha conforme shared/pr-flow.md antes de publicar, sem bloquear o setup.

```yaml
ready-for-agent: null
in-progress: null
in-review: null
needs-human: null
category:feature: Feature
category:fix: Bug
chaos:passed: null
chaos:found-bugs: null
required: []
```

Improvement também está disponível. Não há CI ou remoto para exigir labels de PR. Estados de execução vêm de tracker.md; não aplicar labels ausentes.
