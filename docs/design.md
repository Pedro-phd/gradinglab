# Design

Direção proposta: espaço de edição com mídia como foco e controles de cor legíveis. Não há sistema de componentes escolhido; o scaffold é provisório.

O primeiro fluxo deve mostrar entrada, prévia antes/depois e exportação com estados vazios, erro e progresso. Usar HTML semântico, labels, navegação por teclado, contraste, foco visível e reduced-motion. Evitar transformar características desejadas em alegações de funcionalidades já prontas.
